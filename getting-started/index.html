Getting Started#

OpenSG runs on Linux x86-64 with conda. No GPU is needed. Install it with the four commands of its README:

git clone https://github.com/wenbinyugroup/OpenSG.git
cd OpenSG
conda env create -f environment.yml
conda activate opensg

Check the command:

opensg --help

Then run the plate example of the repository, from the root of the repository:

cd examples/OpenSG-solid/3_get_plate_props_from_2D_SG
opensg RHC_SW_2UC_45.yaml
cd ../../..

It writes the plate law to RHC_SW_2UC_45.out and a picture of the mesh to RHC_SW_2UC_45_mesh.png, next to the yaml. The new RHC_SW_2UC_45.out replaces the one that ships in the folder. The last line goes back to the root of the repository, where every tutorial starts.

The command-line tutorials go on from here: the SG yaml, plate homogenization and dehomogenization, a beam cross-section, a 3-D solid and a shell cross-section, with every output explained. OpenSG's installation page has the CPU-only and the pip routes.
