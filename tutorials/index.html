Tutorials#

These tutorials run OpenSG from the command line with the examples that ship in OpenSG's repository. You can repeat every step on your own machine. Each page gives the command, what it prints and how to read the files it writes. Every number and every output on these pages was copied from a run of OpenSG 2.1.1 on Linux.

The times on these pages, such as the Time taken lines, come from one Linux machine without a GPU. The runs used a Python virtual environment with Python 3.13.15 and JAX 0.11.1, with OMP_NUM_THREADS, MKL_NUM_THREADS and OPENBLAS_NUM_THREADS set to 4. Times vary with the machine, its load and the number of threads. In the environment of the README, 4 threads made the runs several times slower, and 1 thread was the fastest. The install page gives the times.

Start with the install. Read the SG yaml page once, then take the examples in any order. Each tutorial starts in the root of the repository, the OpenSG folder of the clone, and goes back there at its end.
