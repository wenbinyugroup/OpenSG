07 Shell beam cross-section#

The shell engine homogenizes a thin-walled cross-section described by its contour. Each element of the contour carries a laminate. This tutorial computes the Timoshenko law of a wind-blade cross-section.

The SG#

examples/OpenSG_shell/1_get_beam_props_from_shell_cross_section/iea_s10_shell.yaml is one station of a wind blade. The contour has 307 nodes and 310 two-node elements. It spans 7.17 m along y2 (-2.46 to 4.71 m) and 2.50 m along y3 (-1.22 to 1.27 m). The file is in SI units: m, Pa and kg/m^3. The SG yaml page shows its blocks.

This is the iea_s10_shell_mesh.png that the run below writes. Its horizontal axis is y2 and its vertical axis is y3. OpenSG labels them y1 and y2, after the first and the second node coordinate. Each colour is one set of elements with its own laminate. The legend gives the element count and the wall thickness of each set.

The nodes of this file lie on the mid-surface of the walls. The run therefore passes --center. Without it OpenSG takes the contour as the outer mold line and stacks every laminate inward from it.

Run it#

Run it in the example folder. From the root of the repository:

cd examples/OpenSG_shell/1_get_beam_props_from_shell_cross_section
opensg iea_s10_shell.yaml --center --mesh

--mesh adds the mesh picture and iea_s10_shell.msh, the contour for gmsh. The run prints, among other lines:

 input     : .../1_get_beam_props_from_shell_cross_section/iea_s10_shell.yaml
 msg       : shell
 SG dim    : 2D
 analysis  : homogenization
 macro model: beam, shear-refined
 reference : center (contour = laminate mid-surface; ABD shifted by t/2, recovery depths -t/2..+t/2)
 note      : the yaml's `reference: center` key is ignored (the reference is a run-time choice) -- it agrees with this run

It writes these files next to the yaml:

The new _Timo.out and _ABDG.out replace the two that ship in the folder. The folder also ships abd/iea_s10_shell_abd.yaml, the same wall laws as yaml. OpenSG writes that file only when it is missing or holds another reference surface. Its reference: mid matches --center, so the run keeps it.

The couplings are large here. Extension couples with both bending curvatures (C15 = 1.6686413E+009 N m, C16 = -2.0773040E+009 N m), and the two bending curvatures couple (C56 = -5.5571249E+009 N m^2). The origin of the contour is not the tension centre of the section, and axes 2 and 3 are not its principal axes. Read the compliance when you need the stiffness of one mode with the others free.
