04 Plate dehomogenization#

Dehomogenization recovers the local strain and stress inside the SG under a macro state of the plate. This tutorial applies a membrane force N11 = 1000 N/mm to the cell of the plate tutorial.

The macro state: a .ff file#

A D run reads <base>.ff next to the yaml. The example folder ships RHC_SW_2UC_45.ff:

# OpenSG dehomogenization macro state -- read by `opensg_solid RHC_SW_2UC_45.yaml D`
# The SG yaml describes the STRUCTURE; this file carries the LOADING.
u:     [0.0, 0.0, 0.0]      # macro displacement u1 u2 u3
theta: [0.0, 0.0, 0.0]      # macro rotation t1 t2 t3 [rad] (about y1 y2 y3)
C:     [[1.0, 0.0, 0.0],       # direction cosines of the macro frame
        [0.0, 1.0, 0.0],       #   (identity = unrotated; overrides theta)
        [0.0, 0.0, 1.0]]
# generalized macro forces, plate [N11 N22 N12 M11 M22 M12]
FF:    [1000, 0, 0, 0, 0, 0]

key

meaning

u

the macro displacement

theta

the macro rotation, in rad

C

the direction cosines of the macro frame, here the identity

FF

the plate forces [N11 N22 N12 M11 M22 M12], here in N/mm and N

OpenSG reads FF: and appends the same forces to the file under 1:, the key it uses for forces:

# upgraded: 1: is the force identifier (== FF)
1: [1000, 0, 0, 0, 0, 0]

A 0: line gives the macro strains [e11 e22 2e12 k11 k22 2k12] instead, which OpenSG uses as they are. Forces are turned into strains through the plate law.

Run it#

Run it in the example folder of the plate tutorial. From the root of the repository:

cd examples/OpenSG-solid/3_get_plate_props_from_2D_SG
opensg RHC_SW_2UC_45.yaml D --global

D homogenizes the cell, then recovers the local fields. --global writes the stress and the strain in the SG axes, which are the plate axes 1, 2 and 3 here, for every element. Without the flag OpenSG writes them in the ply axes of each element. The file names then drop _global: RHC_SW_2UC_45_dehom.SM, RHC_SW_2UC_45_dehom.EM and RHC_SW_2UC_45_dehom_elemental.SM.

The first lines of RHC_SW_2UC_45_dehom_global.SM:

# RHC_SW_2UC_45_dehom plate dehom stress (units follow the SG input system)
# lattice: element Gauss points (19920), SwiftComp storage reordered to 11 22 33 12 13 23 on write; frame: global (SG axes); z = 0 is the reference surface
#         x[m]           y[m]           z[m]        S11[Pa]        S22[Pa]        S33[Pa]        S12[Pa]        S13[Pa]        S23[Pa]
  0.000000e+00   1.754067e+01   2.329375e+01   4.981684e+01  -2.622229e-01  -3.676725e-01   2.055458e+01   4.181603e-02   2.936096e-01

  • The columns are the position x y z, then S11 S22 S33 S12 S13 S23.

  • x, y and z are y1, y2 and y3. A 2-D SG leaves x at 0. z is the thickness coordinate y3, and z = 0 is the reference surface, the mid-plane of this cell.

  • The column labels say Pa and m. The numbers are in the units of the yaml: MPa and mm here.

.EM has the same layout with E11 E22 E33 E12 E13 E23. Its shear strains are engineering strains, twice the tensor strains: on the core, S12/E12 is 26540 MPa, the shear modulus of material 3. .U holds U1 U2 U3 in mm. Here that is the warping of the cell alone, because u is zero and C is the identity in the .ff.

The .txt holds the same strain and stress in the order xx yy zz yz xz xy, one row per Gauss point. Its xx, yy and zz are the axes 1, 2 and 3, as in the .SM. Its Coord_X and Coord_Y are y2 and y3:

Draw a stress field#

The .vtk opens in ParaView. A short Python script with meshio and matplotlib draws it too. plot_dehom_vtk.py:

"""Draw S11 of an OpenSG plate dehomogenization from its .vtk, and print the plate force it carries.

Run it in the folder of the run:  python plot_dehom_vtk.py
"""
import struct

assert struct.calcsize("P") == 8  # OpenSG runs on 64-bit Python

import re

import matplotlib.pyplot as plt
import meshio
import numpy as np

stem = "RHC_SW_2UC_45"
m = meshio.read(stem + "_dehom.vtk")
tri = m.cells_dict["triangle"]                              # one triangle per SG element
s11 = np.ravel(m.cell_data_dict["Sig_xx"]["triangle"])     # the element mean of S11
x, y = m.points[:, 0], m.points[:, 1]                       # the node coordinates y2 and y3

fig, ax = plt.subplots(figsize=(5.6, 6.0))
tpc = ax.tripcolor(x, y, tri, facecolors=s11, cmap="jet", edgecolors="none")
ax.set_aspect("equal")
ax.set_xlabel("$y_2$ (mm)")
ax.set_ylabel("$y_3$ (mm)")
fig.colorbar(tpc, ax=ax, pad=0.04, fraction=0.06).set_label("$S_{11}$ (MPa)")
fig.savefig(stem + "_dehom_S11.png", dpi=200, bbox_inches="tight")

# the force per unit width that S11 carries: N11 = (sum of element area x S11) / omega
p = m.points[tri][:, :, :2]
d1, d2 = p[:, 1] - p[:, 0], p[:, 2] - p[:, 0]
area = 0.5 * np.abs(d1[:, 0] * d2[:, 1] - d1[:, 1] * d2[:, 0])
omega = float(re.search(r"omega\s+([0-9.eE+-]+)", open(stem + ".out").readline()).group(1))
print("omega = %.6f mm" % omega)
print("N11   = %.4f N/mm" % (np.sum(area * s11) / omega))
print("S11   = %.1f to %.1f MPa" % (s11.min(), s11.max()))

Save it in the folder of the run and run it there:

python plot_dehom_vtk.py

omega = 35.248001 mm
N11   = 999.9999 N/mm
S11   = 24.7 to 262.0 MPa

S11 is the stress along axis 1, normal to the picture. Material 3, the honeycomb core, carries 221.9 to 262.0 MPa. The +45 and -45 face plies carry 24.7 to 74.1 MPa. The stress adds up to the applied force: the script finds N11 = 999.9999 N/mm against the 1000 N/mm of the .ff.

The strain E11 is the same at every Gauss point, 3.537756E-03 to 3.537758E-03. That is the macro strain e11: the compliance entry 3.5377569E-006 mm/N of RHC_SW_2UC_45.out times N11 = 1000 N/mm.
